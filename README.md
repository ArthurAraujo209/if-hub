📖 Sobre o Projeto

O SIMPLIF é uma plataforma web criada para centralizar informações acadêmicas e ferramentas úteis para estudantes do IFRN Campus Santa Cruz.

A ideia do projeto é reunir em um único lugar recursos importantes para os alunos, como dashboards, informações do campus e ferramentas acadêmicas, tornando o acesso às informações mais rápido, organizado e moderno.

Além disso, o projeto foi desenvolvido como um Progressive Web App (PWA), permitindo que ele seja instalado no celular como um aplicativo.

---

Link na Web: https://simplifrn.vercel.app

---

✨ Funcionalidades

- 📊 Dashboard do aluno
- 📅 Visualização de informações acadêmicas
- 🏫 Database de salas do campus
- 🔎 Consulta de dados organizados por ano
- ⚡ Interface rápida e otimizada
- 📱 Instalação como aplicativo (PWA)
- 🌐 Integração com API externa
- 📦 Organização modular do JavaScript
