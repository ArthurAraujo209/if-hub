Política de Privacidade — SimplIF

Última atualização: 23 de setembro de 2026

1. Quem somos

O SimplIF é uma aplicação independente, desenvolvida por Arthur Lima Araújo, criada para facilitar o acesso a informações acadêmicas do Instituto Federal do Rio Grande do Norte (IFRN) por meio da API oficial do SUAP.

O SimplIF não é afiliado, patrocinado nem endossado pelo IFRN. É um projeto independente de extensão acadêmica.

2. Dados que coletamos

Para oferecer as funcionalidades do aplicativo, o SimplIF coleta e armazena os seguintes dados fornecidos pela API oficial do SUAP após a autenticação do usuário via OAuth2:

  • Nome — exibido no dashboard e no perfil
  • Endereço de e-mail acadêmico — exibido no perfil
  • Matrícula (ID de usuário) — utilizada como identificador da conta
  • CPF — retornado pelo SUAP e armazenado no perfil do usuário
  • Data de nascimento — retornada pelo SUAP e armazenada no perfil do usuário
  • Foto de perfil (URL) — exibida no dashboard e no perfil
  • Campus, curso e IRA — utilizados para personalizar a experiência
  • Tokens de acesso ao SUAP (access_token e refresh_token) — utilizados para consultar os dados acadêmicos em tempo real
  • Token de notificações push (FCM) — utilizado para enviar notificações sobre notas, faltas e próximas aulas
  • Identificador Firebase (UID) — utilizado para autenticação e sincronização

3. Como usamos os dados

Os dados coletados são utilizados exclusivamente para:

  • Autenticar o usuário no aplicativo
  • Exibir informações acadêmicas (notas, frequência, horários, disciplinas, avaliações, materiais)
  • Enviar notificações personalizadas solicitadas pelo próprio usuário
  • Manter a sessão ativa entre aberturas do aplicativo

O SimplIF não vende, não aluga e não compartilha dados pessoais com terceiros para fins comerciais, publicitários ou de marketing.

4. Onde os dados são armazenados

Os dados são armazenados em servidores seguros do Google Firebase (Cloud Firestore), sob a responsabilidade do desenvolvedor. A comunicação entre o aplicativo, o servidor intermediário e o SUAP é feita exclusivamente por conexões criptografadas (HTTPS/TLS).

Os dados acadêmicos consultados (notas, faltas, boletins, horários, materiais) não são armazenados permanentemente: são consultados em tempo real na API do SUAP a cada requisição e apenas apresentados ao usuário.

5. Autenticação

A autenticação é realizada através do sistema oficial do SUAP/IFRN via OAuth2. O SimplIF não solicita nem armazena a senha do usuário. As credenciais são tratadas exclusivamente pelo sistema de autenticação do IFRN.

6. Exclusão de dados

O usuário pode solicitar, a qualquer momento, a exclusão completa dos dados armazenados pelo SimplIF. O processo é descrito em detalhes na página:

Solicitação de Exclusão de Dados — SimplIF

A exclusão é processada em até 7 dias úteis a partir do recebimento da solicitação. Após a exclusão, o usuário perde o acesso ao aplicativo e deve autenticar-se novamente caso deseje voltar a usá-lo.

A exclusão dos dados do SimplIF não exclui a conta do usuário no SUAP/IFRN. Para excluir ou alterar dados no SUAP, o usuário deve contatar diretamente o IFRN.

7. Segurança

Adotamos medidas técnicas razoáveis para proteger os dados armazenados, incluindo:

  • Comunicação criptografada em trânsito (HTTPS/TLS)
  • Armazenamento em infraestrutura do Google Firebase com controles de acesso
  • Tokens de acesso com expiração automática e renovação

O SimplIF não possui controle sobre a infraestrutura, autenticação ou segurança interna do SUAP/IFRN. Essas responsabilidades pertencem aos sistemas do IFRN.

8. Serviços de terceiros

O SimplIF utiliza os seguintes serviços de infraestrutura:

  • Google Firebase (Auth + Cloud Firestore + Cloud Messaging) — autenticação, armazenamento e notificações
  • Render — hospedagem do servidor intermediário
  • SUAP/IFRN — fonte oficial dos dados acadêmicos

Nenhum desses serviços é utilizado para publicidade, rastreamento ou compartilhamento comercial dos dados pessoais do usuário.

9. Menores de idade

O SimplIF é destinado a alunos regularmente matriculados no IFRN. O uso por menores de idade deve ocorrer com o consentimento dos responsáveis legais.

10. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada caso ocorram mudanças nas funcionalidades ou na forma como o SimplIF funciona. A versão mais recente estará sempre disponível nesta página, com a data de atualização no topo.
