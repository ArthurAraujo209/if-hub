O SimplIF é um portal acadêmico independente para estudantes do Instituto Federal do Rio Grande do Norte. Acesse dados acadêmicos integrados ao SUAP/IFRN, acompanhe sua rotina de estudos e encontre informações úteis do campus pelo computador ou celular.

Dúvidas frequentes sobre o SimplIF

O que é o SimplIF?

É uma aplicação independente que reúne ferramentas e informações acadêmicas para estudantes do IFRN.

Como faço login?

Use o botão acima para entrar pelo sistema oficial SUAP/IFRN. O SimplIF não solicita sua senha diretamente.

O SimplIF substitui o SUAP?

Não. O SUAP/IFRN continua sendo o sistema oficial; o SimplIF oferece uma forma complementar de consultar informações acadêmicas de uma forma mais simples para o dia a dia.
